# Scratch克隆与闯关 · 8 关分身术到陨石闯关

学会用"克隆自己"造分身，再用分身做出一整个闯关游戏

## 这是什么

一套以 Scratch 图形化积木为载体的编程课，8 个关卡从"克隆自己"造分身开始，认识"当作为克隆体启动时"、克隆体独立运动、本体与克隆体分工，再学会用私有变量给每个分身各记各的数、用计时器做倒计时判定、用关卡变量实现"闯过一关进下一关"，最后综合做出一个"躲避陨石"闯关小游戏。每关配齐关键练习、火眼金睛拆题、三级思路对比、照妖镜用例和教学卡片，孩子自己搭、自己试、自己修。

## 适合谁

适合 10 岁、已经会用 Scratch 基础积木（移动、重复执行、碰到侦测）的孩子。解决"只会复制别人的作品""一碰到克隆就分不清本体和分身""做完一个效果却做不出一整个游戏"的问题。家长不需要懂编程，照着卡片里的积木序列描述就能一起搭；遇错时用照妖镜的妖怪口诀引导孩子自己找错，不直接给答案。

## 怎么用

1. 跟着每关的教学卡片，在 Scratch 里从零搭出积木序列
2. 先让孩子自己试火眼金睛题，再对答案看拆解
3. 用豆包陪练指令让 AI 当陪练出题、批改思路

## 内容结构

- 关卡1 · 认识克隆：分身术：能说出"克隆自己"积木的作用，能区分本体和克隆体
- 关卡2 · 当克隆体启动：会用"当作为克隆体启动时"给克隆体单独写脚本，让每个分身都执行属于自己的代码
- 关卡3 · 克隆体的独立运动：能让克隆体各自独立地移动，走不同的路、有不同的大小和速度，互不影响
- 关卡4 · 克隆体与本体分工：能设计"本体隐藏只克隆、克隆体出现去干活"的分工模式，并理解先克隆再隐藏的原因
- 关卡5 · 变量在克隆中的运用：一人一份：能创建"仅适用于当前角色"的变量，让每个克隆体各记各的数据（速度、编号、大小）
- 关卡6 · 计时器与闯关判定：会用"计时器归零"和读取，会做"剩余时间"倒计时，并搭出"时间到"的闯关判定
- 关卡7 · 关卡切换：闯过一关进下一关：会用"关卡"变量记录当前关卡，按关卡改变难度，实现"闯过一关进下一关"
- 关卡8 · 小结项目：躲避陨石闯关：独立完成"躲避陨石"闯关小游戏：飞船躲避克隆陨石、限时通关、判定输赢

- 分龄启蒙活动设计（情境引入 → 概念演示 → 动手操作 → 调试分享）
- 学习路径定位与阶段通关标准
- 豆包 AI 陪练指令包
